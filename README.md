## ⚡ Key Projects

### 🧠 **Cortex** *(In Progress)*
> **A Django backend engine for treating LLMs (Gemini, Claude, GPT) as first-class asynchronous backend dependencies.**

<details>
<summary>🔍 <b>View Architectural Highlights</b></summary>

* **Structured Output Pipeline:** JSON Schema enforcement and automated retries for malformed model outputs.
* **Async Processing:** Offloaded heavy inference calls using **Celery + Redis** to maintain rapid request/response cycles.
* **Tool & Function Calling:** Native integration mapping structured LLM tool outputs directly to Django ORM operations.
* **Resiliency & Cache Layer:** Rate-limited request queuing, custom prompt versioning, and cached response layers.
* **Stack:** `Django` · `DRF` · `Celery` · `Redis` · `PostgreSQL` · `Gemini/Claude APIs`

</details>
