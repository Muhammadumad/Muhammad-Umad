### 🧠 **Cortex — Production LLM Backend Engine**
> **A specialized Django layer that turns raw LLM APIs into stable, enterprise backend operations.**
<details>
<summary>🔍 <b>View Technical Highlights</b></summary>

* **Asynchronous Execution:** Heavy LLM calls handled in background queues using **Celery + Redis** to prevent blocking HTTP endpoints.
* **Schema Enforcement:** Strict JSON schema validation and retry triggers for malformed model outputs.
* **Tool-Calling Integration:** Directly bridges LLM function calls with native **Django ORM** models and database records.
* **Stack:** `Django` · `DRF` · `Celery` · `Redis` · `PostgreSQL` · `LLM APIs`

</details>
